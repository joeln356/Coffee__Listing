### ✨ Sobre o Projeto

**Coffee Listing** é uma interface moderna para exibição de cafés, criada com foco em design limpo, responsividade e experiência visual agradável.

Principais características:
- Interface moderna e minimalista
- Layout responsivo
- Componentização com React
- Build rápida usando Vite
- Deploy com GitHub Pages
